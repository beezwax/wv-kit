# wv-kit Example — Kensington

A two-viewer product catalog using Kensington's reactive signals and computed values.

## Setup

```bash
npm install
npm start
```

Open http://localhost:3000

## What this demonstrates

- Reactive state with `signal` and `computed`
- `t.*` element builders with inline event handlers
- `computed(() => ...)` for derived list rendering
- `addConnectedCallback` for post-mount DOM work
